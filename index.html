Part 1 — Architecture Trade-Off
Traditional NN/Transformers vs. PINNs

The golden rule: "Choose by problem structure, not hype." Wrong architecture = 10× more data needed to compensate for mismatched inductive bias.

Self-Attention Mechanism

Transformer-Based Architecture

Captures long-range temporal dependencies critical for degradation trend detection. The attention mechanism acts as a differentiable lookup table.

Attention(Q, K, V) = softmax(QKT / √d_k) · V

Q = "What am I looking for?" · K = "What does each token contain?" · V = "Content to retrieve"

Multi-Head Specialization

Parallel Attention Heads

Each head learns different roles simultaneously:

Head 1Vibration frequency patterns
Head 2Temporal degradation trends
Head 3Cross-sensor correlation
Head 4Syntax/structure patterns
Advantages ✓
  • ✓ Captures complex nonlinear degradation without explicit physics
  • ✓ Processes variable-length flight sequences
  • ✓ Residual connections (ResNet-inherited) ensure stable gradient flow
  • ✓ Proven at scale — backbone of GPT, BERT, Llama
Critical Limitations ✗
  • ✗ O(n²d) attention cost — 100k timesteps → 1010 entry matrix
  • ✗ May learn spurious correlations (ambient temp ≠ degradation)
  • ✗ No physics grounding — predictions may violate thermodynamics
  • ✗ Requires massive labeled failure data (rare in aviation)
Session 3 · Slide 15

Memory: O(n²) · FLOPs: O(n²d). Mitigation: Flash Attention, sliding window attention, sparse attention.

Physics as Loss Function — Raissi et al., 2019

Physics-Informed Neural Networks

Embed physical laws directly into the training loss. The network is forced to satisfy governing equations.

L_total = L_data + λ · L_physics
λ = 0.01
Ignores physics; overfits noise
λ = balanced
L_data ≈ L_physics at convergence
λ = 100
Ignores data; solves PDE only
Gas Turbine Physics

Governing Equations Enforced

  • • Brayton cycle thermodynamic relations
  • • Rotordynamic equations of motion: P·τ = I·α
  • • Fourier's law: heat conduction through turbine blades
L_phys = (1/N_c) Σ [∂u_θ/∂t − α ∂²u_θ/∂x²]²

Data Leakage Prevention

Three Critical Leakage Sources — RUL Time-Series

⏰

Temporal Leakage

Future sensor readings inadvertently inform past predictions. Fix: strictly chronological train/val/test splits — never random shuffling of flight sequences. March 2025 flights must not train on Feb 2025 test data.

✈

Cross-Unit Leakage

Same physical engine in both training and test sets at different time points. Each engine has unique degradation signatures. Fix: engine-level splitting — entire engine histories assigned to either training OR testing, never both.

🔀

Feature Leakage

"Reduced thrust setting" is both a feature and a consequence of detected degradation — the model learns a trivial shortcut. Fix: audit features for causal ordering relative to the target variable.

Part 3 — Compute Reality
Matrix Operations, Memory & Scaling

Every neural network operation is tensor math. Understanding the bottlenecks is essential for production deployment decisions.

GEMM Dominates — ~99.5% of FLOPs

General Matrix Multiplication

FLOPs = 2 × m × n × p

For d_model = 4096: 2 × 4096³ ≈ 137 GFLOPs per matrix multiply.

Forward pass FLOPs ≈ 2 × N_params × N_tokens

GPT-3 (175B params) × 2048 tokens ≈ 314 TFLOPs per forward pass (~1 sec on A100)

Roofline Model

Compute vs. Memory Bound

Large MatMul (compute-bound) ~85% GPU util
Softmax / LayerNorm (memory-bound) ~10% GPU util
Single inference request ~5% GPU util
Implication

Consolidate small ops. Maximize matrix sizes. Batch aggressively. A100 HBM: 2.0 TB/s bandwidth.

AspectTrainingInference
FLOPs per token 6N (fwd + bwd + optimizer) 2N (forward only)

KV Cache Growth

Inference Memory Trap

KV cache = 2 × L × 2 × d × T bytes

LLaMA-70B at sequence length 4096 → ~20 GB KV cache alone. Must be managed with continuous batching (vLLM/TGI).

Throughput vs Latency

Production Strategy

Continuous batching dynamically adds/removes requests — industry standard (vLLM, TGI).

Quantization trades numerical precision for speed and memory savings. Critical for deploying 70B models on limited hardware.

Our System Decision

INT8 quantization reduces the model from 140 GB to 70 GB while maintaining acceptable accuracy — enabling deployment on a single A100 GPU. With INT4, 70B fits in 35 GB (well under 80 GB HBM3), making self-hosting economically viable at fleet scale.

Kaplan Scaling Laws, 2020

Performance Follows Power Law

L(N) ≈ (N_c / N)^α · α ≈ 0.076

Loss decreases as power law of model size N. Performance is predictable before training.

L(C) ≈ (C₀/C)^α_C · α_C ≈ 0.05

10× compute → only ~12% loss reduction. Gains per dollar decrease over time.

Economic Reality

Scaling eventually hits economic limits, not technical ones. We can predict model performance before expensive training runs — critical for budget planning.

Part 4 — Integrated Recommendation
The Engineering Manager's Verdict

Combining Sessions 3–5 insights into a production-ready strategy for 200-aircraft fleet deployment.

Architecture

GNN + Transformer + PINN

Topology (GNN) + Dynamics (Transformer) + Physics (PINN). Directly follows Session 3 frontier design. Thermodynamically plausible even for novel fault modes.

Data Strategy

Quality Before Complexity

Allocate 80% of initial effort to data curation. Active learning. CFD synthetic augmentation (L2 fidelity). Continuous MMD drift monitoring.

Compute

Self-Hosted 7B + INT8

Single A100 GPU with INT8 quantization. ~$5k training + ~$500/month retraining. <100ms latency for 200 aircraft streams via continuous batching.

01
Data Audit First
Run full 5-dimension quality check. Q_total < 0.7 → fix data before training anything.
02
Engine-Level Splits
Chronological train/val/test. Entire engine histories in one set only. No cross-unit leakage.
03
CFD Synthetic Data
For rare events (<0.03% HPC stall): 200+ CFD events, physics-validated within 5% divergence pressure.
04
Deploy MMD Monitor
Online sliding window. Alert when MMD > 3σ baseline. Trigger retrain or human review automatically.
05
Safety-Weighted Loss
L_safety = Σ w_i · ℓ_i where w_i ∝ severity. Decoupled training for long-tail rare faults.
06
PINN as Safety Net
Even OOD inputs remain thermodynamically plausible. Physics-consistency is the production safety guarantee.
